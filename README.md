# Vini Mandalika — Portfolio Website

A premium, elegant, and dreamy personal portfolio website showcasing professional experience, education, certifications, and skills in office administration and digital technologies.

## 🎨 Design Concept

This portfolio embodies a romantic digital art gallery aesthetic with:
- **Strict Two-Color Palette**: Petal Reverie (#F4C9D6) and Ivory Hearth (#F5F0E6)
- **Elegant Typography**: Cormorant Garamond for headings, Lato for body text
- **Minimalist Editorial Composition**: Sophisticated, clean, and visually captivating
- **Premium Feminine Aesthetics**: Dreamy pastel art gallery inspired design

## ✨ Features

- **Responsive Design**: Optimized for desktop, tablet, and mobile devices
- **Interactive Sections**:
  - Hero section with professional introduction
  - About Me with highlight cards
  - Professional Experience timeline
  - Education details
  - Organizational Experience
  - Certificate Gallery with detailed modals
  - Portfolio Gallery showcasing projects
  - Skills organized by category
  - Creative Journal section
  - Contact information
- **Smooth Animations**: Elegant transitions and micro-interactions
- **Accessible Navigation**: Smooth scrolling and clear structure
- **Certificate Modal**: Detailed certificate viewer with skills breakdown

## 🛠️ Tech Stack

- **React** 18.3.1
- **Vite** 5.3.4
- **HTML5** with semantic markup
- **CSS3** with modern features
- **JavaScript** ES6+

## 🚀 Getting Started

### Prerequisites

- Node.js (v16 or higher)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/portofolio.vinimandalika.git
   cd portofolio.vinimandalika
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open your browser and visit: `http://localhost:5173`

## 📦 Building for Production

Build the project:
```bash
npm run build
```

Preview the production build:
```bash
npm run preview
```

## 🌐 Deployment

See [DEPLOYMENT.md](DEPLOYMENT.md) for detailed deployment instructions for GitHub Pages.

Quick deploy:
1. Update `base` path in `vite.config.js` if needed
2. Run: `npm run build`
3. Deploy the `dist` folder to your hosting service
