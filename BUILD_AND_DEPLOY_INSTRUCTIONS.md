## 📁 WHAT EACH FILE DOES

### `index.html` (root)
**Purpose**: Development entry point  
**Used by**: Vite dev server (`npm run dev`)  
**References**: `/src/main.jsx` (source file)  
**NOT deployed**: This file should NOT be deployed to production

### `dist/index.html` (generated)
**Purpose**: Production entry point  
**Used by**: Production deployment  
**References**: Compiled JS/CSS with hashes  
**Deployed**: This is what GitHub Pages should serve  
**Generated by**: `npm run build`

### `.github/workflows/deploy.yml`
**Purpose**: Automates build and deployment  
**Does**:
1. Runs `npm ci` (install dependencies)
2. Runs `npm run build` (creates `dist` folder)
3. Uploads `dist` folder as artifact
4. Deploys artifact to GitHub Pages

### `public/.nojekyll`
**Purpose**: Tells GitHub Pages to skip Jekyll processing  
**Why needed**: Vite uses `_` prefixed files that Jekyll would ignore

## 🔄 BUILD PROCESS EXPLAINED

### Development (npm run dev)
```
index.html → /src/main.jsx → React components
(Source files, no compilation)
```

### Production (npm run build)
```
vite build
  ↓
Creates dist/ folder
  ↓
dist/index.html → /portofolio.vinimandalika/assets/index-[hash].js
  ↓
All React compiled into optimized bundles
```

### GitHub Actions Deployment
```
1. git push origin main
  ↓
2. Workflow triggers
  ↓
3. npm ci (install)
  ↓
4. npm run build (create dist/)
  ↓
5. Upload dist/ folder
  ↓
6. Deploy to GitHub Pages
  ↓
7. Site live at vinimandalika.github.io/portofolio.vinimandalika/
```

## 🆘 TROUBLESHOOTING

### Problem: Workflow doesn't appear in Actions tab

**Cause**: GitHub Pages source not set to GitHub Actions

**Solution**:
1. Settings → Pages → Source: `GitHub Actions`
2. Commit and push any change
3. Workflow should trigger

### Problem: Workflow fails on "npm ci"

**Cause**: `package-lock.json` out of sync

**Solution**:
```bash
rm -rf node_modules package-lock.json
npm install
git add package-lock.json
git commit -m "Update package-lock.json"
git push origin main
```

### Problem: Still seeing main.jsx error

**Cause**: Build completed but GitHub Pages is serving wrong files

**Solution**:
1. Verify Pages source is GitHub Actions (not branch)
2. Check workflow logs for "Upload artifact" step
3. Ensure artifact contains dist folder contents
4. Clear browser cache: Ctrl+Shift+R

### Problem: Workflow succeeds but site is blank

**Cause**: Base path mismatch

**Solution**:
Verify `vite.config.js` has:
```javascript
base: '/portofolio.vinimandalika/',
```
Must match repository name exactly
