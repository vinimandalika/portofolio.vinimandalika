## ✨ Design Highlights

### Color Usage Examples
- **Backgrounds**: Ivory Hearth with gradient variations
- **Accents**: Petal Reverie for headings, buttons, highlights
- **Borders**: Petal light opacity for subtle separation
- **Shadows**: Petal medium opacity for card elevation
- **Text**: Petal dark opacity for excellent contrast

### Animation Examples
- **fadeIn**: Hero image, about highlights
- **fadeInUp**: Cards, sections (0.8s ease-out)
- **Hover effects**: Cards lift (-5px to -8px)
- **Smooth transitions**: 0.3s ease on all interactive elements
- **Transform effects**: Navbar underlines, button hover states

### Typography Hierarchy
- **H1**: 2.5rem - 4.5rem (Hero name)
- **H2**: 2rem - 3.5rem (Section titles)
- **H3**: 1.5rem - 2.5rem (Card titles)
- **H4**: 1.25rem - 2rem (Subtitles)
- **Body**: 1rem - 1.1rem (Paragraphs)
- **Small**: 0.85rem - 0.95rem (Tags, metadata)
